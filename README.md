# Automated Bank Statement Reconciliation 📊

This project demonstrates an end-to-end data pipeline built for accounting and financial analysis in the UK market.

**Garay Tech Partners - Portfolio Project**

## 🛠️ Tech Stack
* **Data Extraction & Cleaning:** Python (Pandas, OS, Glob)
* **Version Control:** Git & GitHub
* **Data Visualization:** Power BI

## 💡 Use Case
Automates the merging of multiple monthly bank statements (CSV), removes duplicate transactions, and visualizes income/expenses to accelerate the month-end reconciliation process for accounting firms.
